# Problema-de-los-N-Cuerpos-Paralelizacion
Este proyecto implementa la simulación del Problema de los N Cuerpos, el cual modela el movimiento de cuerpos que interactúan entre sí bajo la ley de gravitación universal de Newton. Como el cálculo de fuerzas entre todos los cuerpos es de O(N²), el objetivo es reducir el tiempo de ejecución mediante de programación paralela.
